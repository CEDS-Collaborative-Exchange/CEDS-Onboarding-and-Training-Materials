# Michigan CEDS-Onboarding-and-Training-Materials
This collection provides an overview of Michigan’s approach to onboarding staff and building capacity to engage with the Common Education Data Standards (CEDS). The materials are designed to help new team members, project partners, and other state agencies understand how to contribute to CEDS through use cases, alignments, and proposals.

Folder/File	Description
1. Data Governance - Maps, Gaps and Use Cases 101.<br> <br>
   - "Data Governance" (PowerPoint) - An intro to data governance is and the role it plays in migrating data to CEDS; includes a _brief_ overview of the gap resolution process and how to create a use case. <br> <br>
   - "Gap Resolution Scenarios" (PowerPoint) - A collection of brief case studies from Michigan highlighting the types of gaps an organization might encounter when migrating data to CEDS and how to resolve those gaps. <br> <br>
   - "Learning How to Create Use Cases" (Word Document) - Detail descriptions and time-stamped outlines of three OSC Webinars.  Want more help with some aspect of the use case process?  Skim the time-stamped outlines to determine which webinar to watch -- or even which section you can skip to! <br> <br>
   - "Michigan Align Process" (Word Document) - An example of one of Michigan's internal documents guiding its users through Michigan's data governance process when aligning data elements to CEDS.  <br> <br>
2. Transactional CEDS - Understanding the IDS, the Ontology, and JSON-LD <br> <br>
     - "An Intro to CEDS in Transactional Systems" (PDF) - A beginner's guide to understanding how the CEDS Ontology works in transactional systems (i.e. in databases used by applications).  This training uses visuals, examples, and analogies to help users understand how the CEDS Integrated Data Store (IDS) structures data, how the IDS structures can be used to help understand the CEDS Ontology, the benefits of the CEDS Ontology, and how to implement the Ontology if you are storing data in JSON-LD.  Primary goals focus on understanding the benefits of CEDS as well as the most common structures and conventions associated with IDS, Ontology, and JSON-LD. <br> <br>
     - "Classes and Object Properties - PowerPoint Activity - PUBLIC" (PowerPoint) - This is an interactive 'click-and-drag' activity where users can interact with shapes that represent classes, object properties, and concept schemes from the CEDS Ontology.  This activity is designed for individuals who are new to working with ontologies.  By rearranging the shapes according to the activity 'rules', the user experiences how object properties are used to 'link' classes or classes and concept schemes.    <br> <br>
3. z_Archive - This folder holds past trainings that were based on retired features of the CEDS website (such as the Domain Entity Schema).  These trainings are archived as examples of documentation, but no longer recommended for active training. <br> <br>
